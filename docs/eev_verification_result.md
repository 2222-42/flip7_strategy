# Flip7における期待探索価値（EEV）の検証報告

## 1. 概要
ボードゲーム「インカの黄金」の検証（`search_result.md`）で得られた「期待利得と期待損失を比較し、よりリスクテイカー（More Risky）な戦略が圧倒的優位性を持つ」という知見が、本作「Flip7」においても成り立つかを検証しました。

本検証では、Flip7のメカニクスに合わせて「期待探索価値（Expected Exploration Value: EEV）」の計算をロジック化し、リスク許容度（Risk Tolerance）としきい値を変化させながら数万回のモンテカルロ・シミュレーションを実施しました。

## 2. EEVの計算式と定義
Flip7におけるEEVは、以下の式に基づき計算されます。
1枚カードを引いた際の影響を全残存カードについてシミュレーションし、

* **利得 (Upside)**: 引いて「バーストしなかった」場合のスコアの平均増分（期待ゲイン）
* **損失リスク (Downside)**: 引いて「バーストした」場合に失う現在の全スコア

```
EEV = Upside - Downside
```

これに対して、**リスク許容度 (RiskTolerance)** という変数を導入し、
**「EEV > RiskTolerance」**を満たす場合のみ「探索継続（Hit）」とする意思決定モデルを作成しました。
* RiskTolerance = `0.0`: 純粋に期待値がプラスの場合のみ引く（標準的なEV最適）
* RiskTolerance < `0.0`: 期待値がマイナスでもリスクを取る（インカの黄金での"More Risky"戦略相当）
* RiskTolerance > `0.0`: 期待値が大きく上回る場合しか引かない（保守的・Conservative）

## 3. シミュレーション検証
各 RiskTolerance （-5.0 〜 5.0）を設定した`ExpectedValueStrategy`を持つAIを、Cautious、Aggressive、Probabilisticの3つの他AIと同卓させ、各閾値につき1,500ゲームの多人数プレイ（4人）を実施・統計処理しました。

          5.0 |   14.33%

## 4. 考察と結論

### リスクテイカー優位性の否定
インカの黄金とは異なり、Flip7においては「純粋な期待値ゼロ分岐点（RiskTolerance = `0.0`）」が最も高い勝率（約35.4%）を記録しました。
これは、以下のゲームデザインの違いに起因すると考えられます。
1. **他者との相互作用（分割と剰余）がない**
   インカの黄金では「同時に撤退した人数で報酬を割る」「途中のアーティファクトは単独撤退者のみが総取りする」といったメカニクスがあり、これらが他者を出し抜くチキンレースや囚人のジレンマを引き起こします。そのため、他者が保守的に降りるほど、強気にリスクを取った際の相対的なリターンが指数関数的に増大します。
2. **Flip7の独立性**
   Flip7のドローとスコアは各プレイヤーで独立しています。特定のカードが山札から除外される全体情報影響はありますが、「期待値を無視して引くことが直接的な追加インセンティブ（独占等）を生む」設計にはなっていないため、数学的な期待値に忠実な行動をとる戦略が長期的には最適（Nash均衡に近似）となります。

### 保守的戦略（Conservative）の弱さ
一方で、RiskToleranceをプラス（保守的）に設定したとたん、勝率が大きく低下（`+3.0`で29%、`+5.0`で14%）する点はインカの黄金のデータと合致しています。「失うリスク」を恐れて安定したところでカードを引かなくなる戦略は、他のプレイヤーが着実に得点を稼いでいる多人数環境下では致命的に不利になります。

### 結論
インカの黄金とは異なり、Flip7においては過度なリスクテイクは不要ですが、**「期待値がプラスである限り、たとえ現在の所持得点を失うリスク（Downside）があっても引き続ける（EEV=0）」**という客観的な期待値最適行動を取ることが最大の勝率を生み出すことが証明されました。
